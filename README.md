# Modern Web Design Project 🎨

A modern and responsive web design project created using Figma Sites. This project showcases a clean user interface, smooth layout structure, and visually appealing design focused on improving user experience and accessibility across different devices.

- Clean and user-friendly interface
- Mobile-friendly layout
- Interactive sections and smooth navigation
